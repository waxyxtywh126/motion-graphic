# Motion Graphic

Proyek Remotion sederhana untuk membuat video animasi 2D/3D-like motion graphic.

## Instalasi

```bash
npm install
```

## Menjalankan editor

```bash
npm run dev
```

## Render video

```bash
npm run render
```

Hasil render akan dibuat di folder `out/video.mp4`.

## Struktur utama

- `src/index.tsx` - point masuk aplikasi Remotion
- `src/Root.tsx` - registrasi komposisi
- `src/Composition.tsx` - animasi utama
- `remotion.config.ts` - konfigurasi Remotion
